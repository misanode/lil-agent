Frequently asked questions

Does it use up any tokens?

Nope — zero! Lil Agent never talks to an AI model. Its hooks just send a tiny ping to the app on your own computer and the reply is thrown away, so nothing gets added to your agent’s context. Your usage limits stay exactly where they were. Your companion is free entertainment.

Can I use it without a coding agent?

Yes. Lil Agent works as a desktop companion on its own. Connect local Claude Code or Codex sessions when you want reactions to agent activity.

Do I need any developer tools?

No. The release downloads are ready to run — no Node.js, npm, Xcode, or terminal commands required. On Mac, unzip and move Lil Agent.app to Applications. On Windows, run the installer.

What permissions does it need?

On Mac, Electron typing reactions require Accessibility access; the native Swift app uses Input Monitoring. Music reactions may ask for permission to check Spotify or Music. Agent integrations are optional and use local hooks.

Electron typing reactions use a US keyboard layout and have no app-level password-field filter. On Windows, this can display characters entered into password fields. Disable typing reactions when entering sensitive information.

How do updates work?

In the Windows Electron app from v1.0.1, click Update Available to download the update, check its checksum, install it, and restart the app. Earlier versions need one manual installation to receive this updater. Windows may still request its normal approval.

The current Mac editions open the release page for a manual download.
